# STOP

Aplicación móvil para jugar STOP con escritura con el dedo o teclado, categorías Normal y Alizabeth, revisión individual y general, y puntuación por rondas.

## Uso

Sirve esta carpeta con cualquier servidor estático. `index.html` carga `app.js` y las cuatro hojas de estilo de la misma carpeta. No requiere instalación de dependencias ni compilación.

## Procedencia

Copia íntegra de los seis archivos publicados en STOP, recuperados del código fuente original, commit `044c566fffef154546d8e7b354978b76cd2d054f`.

Los datos de las partidas se guardan en el navegador con la clave `stop-hand-v1`. Cada dominio conserva sus propios datos.
