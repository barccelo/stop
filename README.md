# STOP

Juego de STOP para móvil, compatible con escritura a mano y teclado.

## Funcionalidades

- Categorías editables y dos grupos: **Normal** y **Alizabeth**.
- Selector de letra y navegación entre respuestas con barra lateral.
- Escritura táctil sobre lienzo, deshacer, borrado con doble confirmación y teclado opcional.
- STOP desactivado hasta completar todas las respuestas. Una opción explícita permite terminar con casillas vacías por acuerdo de los jugadores.
- Revisión general por rondas y categorías, revisión individual, gestos horizontales y puntuación editable.
- Total por ronda y total general. Partidas guardadas localmente en el navegador.
- Tema claro/oscuro y pantalla completa. No requiere librerías, compilación ni servicios externos.

## Cómo abrir

Abre `index.html` en el navegador. Para publicar con GitHub Pages, selecciona la rama `main` y carpeta `/ (root)` en **Settings → Pages → Build and deployment**.

## Origen

Esta versión se reconstruyó a partir de las especificaciones del proyecto STOP. El código fuente original del sitio publicado en ChatGPT Sites no pudo exportarse automáticamente. Por ello, no se presenta como copia binaria exacta de aquel sitio.

El estado se guarda en `localStorage` del dispositivo. Para jugar desde otro teléfono, se necesita abrir el mismo sitio allí; las respuestas no se sincronizan entre teléfonos.
